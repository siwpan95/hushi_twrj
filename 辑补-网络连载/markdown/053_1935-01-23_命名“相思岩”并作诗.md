# 胡适日记——命名“相思岩”并作诗1935.01.23、24

> 辑补卷 · 1935-01-23（另含 1935-01-24）　序号 53 / 69

23日

胡适从阳朔回桂林。

途经良丰时，赴校址为西林公园的省立师范专科学校进行演讲。晚饭后，就夜游校内的雁山。

在游岩洞时，胡适问此岩何名，他们说，“向来没有岩名，胡先生何不为此岩取一个名字，作个纪念？”胡适笑道，“此间附近有相思江，岩边又有相思红豆，何不就叫此岩为相思岩？”他們都赞成。

游毕出园坐汽车回桂林。

24日

胡适早上十点起飞，原本直飞梧州。由于大雾，改飞柳州。

在柳州午饭后，计划飞广州从化，又由于大雨，改降梧州。

上午在空中作一詩：

飛行小赞

看盡柳州山，看遍桂林山水，

天上何須半日，地上五千里。

古人辛苦學神仙，妄想出三界。

看我凡胎俗骨，也飛行無礙。

又戲仿柳州山歌，作小詩寄題良豐相思巖：

相思江上相思巖，相思巖下相思豆。

三年结子不嫌遲，一夜相思教人瘦。
