# 胡适日记——第一次见蒋介石1932.11.28、29、12.02

28日

上午與雪艇、皓白同去參觀武漢大學。

......

下午七時，過江，在蒋介石先生寓内晚餐，此是我第一次和他相見。飯時蒋夫人也出來相見。

今晚客有陳布雷、裴復恆。

29日

六點半，黎琬（公琰）來，小談，同去蔣宅晚飯。

同席者有孟餘、布雷、立夫。今晚無談話機會，我送了一冊《淮南王書》給蒋先生。

12月2日

六點下山，過江。蒋先生的秘書黎琬君來迎，到蒋宅吃飯。

我本來以爲這是最後一個談話機會，故預備與他談一點根本问題。但入門即見昨見的雷孟疆先生，後來吃飯時楊永泰先生又來了。二客皆不走，主人亦無法辭客。所以我也不預備深談了，只隨便談了一會；十點即辭出。

我至今不明白他爲什麼要我來。今日之事，我確有點生氣，因爲我下午還托雪艇告知他前日之約我一定能來。他下午也還有信來重申前日之約。

席上他請我注意研究两個問題：

(1) 中國教育制度應該如何改革？

(2) 學風應该如何整頓？

我很不客氣的對他說：教育制度並不壞，千萬不要輕易改動了。教育之壞，與制度無關。十一年的學制，十八年的學制，都是專家定的，都是很好的制度，可惜都不曾好好的試行。經費不足，政治波動，人才缺乏，辦學者不安定，無計畫之可能，……此皆教育崩壞之真因，與制度無關。

學風也是如此。學風之壞由於校長不得人，教員不能安心治學，政府不悅學，政治不清明，用人不由考試，不重學績……學生大都是好的；學風之壞决不能歸罪學生。

今之詆毀學制者，正如不曾試行議會政治就說議會政治决不可用。

附記：

蒋介石先生要同我談談哲學，他先把他著的五小冊《力行叢書》送給我看。其中第四冊爲「自述研究革命哲學經過的階段」比較最扼要。他想把王陽明「知行合一」「致良知」的道理來闡明我們總理「知難行易」的學說。
