# 胡适日记——拜谒「抗日陣亡将士公墓」1935.07.05

> 辑补卷 · 1935-07-05　序号 57 / 69
> 来源（网络连载转抄，二手来源）：[https://www.bilibili.com/read/cv23414266](https://www.bilibili.com/read/cv23414266)

早晨八點多，白映星、張錫羊諸君來車上，同我們到第三十五軍軍部，傅主席（傅作义）加入，和我們同去看大青山「抗日陣亡将士公墓」。墓地離車站不遠，在車上可望見墓碑塔。

墓碑是我做的，錢玄同寫的，這是第一塊白話碑文用全副新式標點符號分段寫刻的，所以拓本流傳全國。我曾說：「這碑不久會被日本毀滅的。」但我不曾想到日本人還不曾占據綏遠，我的碑已被「埋葬」了！

當上月華北形勢最危險時，小心的何應欽將軍打了幾個電報給傅宜生（傅作义），叫他消滅一切「抗日」的標幟，尤其是這裡的陣亡將士公墓。傅不得已，把塔上「抗日陣亡將士公墓」的「抗日」二字挖改成了「長城」二字，挖改的痕跡尙可認藏。我的碑文也蒙上了一層沙石，另刻上了「精靈在茲」四個大字。全國送來的匾、聯、銘、贊，凡有刺激性的，都設法遷毀了，只剩林（林森）主席的「河山壮氣」一個匾。我站在這二百零三個國殤的墓前，真不勝感概。

塔與墓之間，建有祠堂，中設陣亡將校兵士的照像，各有履歷年歲，有許多兵士在二十歲以下的，有幾個不過十八歲。

碑塔是鋼鐵作骨的，深入地中。據傅主席說，這塔是不容易炸毁的。 傅主席送我們出墓園後，他回軍部去了。

大青山公墓碑

霧散雲開自有時，埋藏隱晦不須悲。

山靈待我重來日，大写青山第二碑。

......

車上我常令小三（胡思杜）打蒼蠅，我也打死不少。莎菲戲說：「賦得父子打蒼蠅」可作詩題。我即口占一詩：

父子打蒼蠅，各出一身汗。

堂堂好男兒，莫作自了漢。
