## 本册特殊的日期写法

册 8 混用三种，分篇时逐一支持：

| 类型 | 示例 | 出现段 |
|---|---|---|
| 公元年月日（阿拉伯） | `1950年1月1日` / `1955 年 1月 25 日` | 1950–1953、1955–1962 |
| 公元年月日（汉字月日） | `1954年二月十八日` | 1954 段开头 |
| 无年份月日 + 星期 | `三月十五日星期` / `四月一日星期四` | 1954 段主体 |

第三种不带年份，靠页眉（`一九五四年*333`、`-九五四年: 331.`）确定年份。
因此页眉正则必须容忍年份后面的页码与装饰符号，且 **中文纪年换算要区分
「民国纪年」（八年 → 1919）与「公元纪年」（一九五四年 → 1954）** ——
后者若再套用 `1911 + n` 会得到 3865 这类荒谬年份。
