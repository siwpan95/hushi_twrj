# 1922年8月28日

窘极了，写信到上海叫亚东寄了一百元来，今天向银
行取出，为思永，泽涵学费。
与玄同在春华楼吃饭，谈《诗经》甚久。玄同赞成我
整理旧书的计划，但我们都觉得此事不易做。现今能做此
事者，大概只有玄同，颉刚和我三人。玄同懒于动手，颉
刚近正编书，我又太忙了，此种事正不知何时方才有人
来做!
现今的中国学术界真瞰零落极了。旧式学者只剩王
国维、罗振玉、叶徳辉、章炳麟四人；其次则半新半旧的
过渡学者，也只有梁启超和我们几个人。内中章炳麟是在
学术上已半僵了，罗与叶没有条理系统，只有王国维最有
希望。
夜到王正廷处吃饭，喝酒稍多，颇不适意。
