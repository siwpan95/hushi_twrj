# 1938年6月23日

李国钦兄从祖国飞回，来看我久谈，他告我国内形
势，令人叹息。他说，“武人可算是尽了他们的责任，中
国如不支，罪在文人”。此言可谓“-语破的”。
他说，国内土气还好，军士真可敬爱；最可叹的是一
班文人至今不知大体，不能合作。
他说，蒋先生可怜，也真可佩服。他是能了解的，可
惜无人辅佐他。
写明晚的演说。
与冀朝鼎，Mr，Jaffe（加福先生】同吃饭。
请王大使，于领事，王止绪夫妇，国钦夫妇，及诸友
在Canton Village【坎顿山庄］吃晚饭。喝多了一点酒，
回来小睡，睡醒起来，已两点钟，继续写演说稿，写成天
已大亮，看表是五点半钟了。
竟不复能睡，就起来看早报，改文字，修改了把稿子
送出。
