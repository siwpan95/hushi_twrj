# 1930年8月4日

祖望从日本回来。他跟沪江大学中学童子军去游览日
本，七月九日去，今天回来。我去接他，遇见陈陶遗、沈
燕谋、胡伯平等，都是来接儿子的。
为中公事，和马君武先生去访游伯麓和一涵。
在张菊生先生处看见四册《永乐大典》。其中杭字-~
册有《武林旧事》，《都城纪胜》，及《都城繁胜录》。《繁
胜录》是我不曾见过的：
①此后附英文剪报一则，题为《中国贫婿的邀产一一中国文明的历史
阐释》，作者胡适。文章内有几个小标题，分别为：一个变化的观
念；佛教的引人；一饮悲剧性的联全；佛教的迫害；反对佛教的斗
争：家庭关系；一份贫膺的遗产等。剪自《字林西报》。底本模糊
难辩，从略。编者
一九二〇年: 749-
