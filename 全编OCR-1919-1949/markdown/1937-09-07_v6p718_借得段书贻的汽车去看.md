# 1937年9月7日

借得段书贻的汽车去看蒋先生，布雷在座。谈半点
钟，他说，他要电告士儒堂大使，今天谈的话很中肯，也
得体。
与盖邻去银行，办印鉴改换事。
慰慈为我们取得旅费换的外汇，发一-电给郑铁如：
王雪艇为我们钱行。
张子下牛才到京。催他去办照相。
与翁咏霓谈甚久，他前天从国外归来。
写信与冬秀、叶良才、山、王云五。
晚上高宗武、程沧波为我们饯行。
听广播，知上海美国商人甚怨SecretaryHull【国务
