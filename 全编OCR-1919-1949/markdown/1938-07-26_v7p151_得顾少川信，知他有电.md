# 1938年7月26日

得顾少川信，知他有电去探询，回电（当是徐读回电）
说政府领袖对儒堂甚不满意，故有此更动.
我拟一电，说“廿余年疏懒已惯，决不能任此外交要
职”，最后推荐施植之，许以“以私人助其疏导舆论"。
林斐成妃见此电稿，大不以为然，他不赞成我此时推
却此事。
夜与复初长谈，他也不赞成我推却：
回寓后又修改此电，半夜后始决，此时恐无法辞
却；既不能辞，不如“伸头-刀”之为爽快。故最后修改
电文为接受此事。
