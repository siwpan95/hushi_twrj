# 1921年5月2日

九时上火车，九时二十分开，十二时到北京。
车中读梁任公先生的《清代学术概论》。此书的原稿，
我先见过，当时曾把我的意见写给任公，后来任公略有所
补正。《改造》登出之稿之后半已与原稿不同，此次付印，
另加惠栋一章，戴氏后学一章，章炳麟一章，皆原稿所
无。此外，如毛西河一节，略有褒辞；袁枚一节全删；姚
际恒与崔适的人，皆是我的意见。
任公此书甚好，今日亦只有他能作这样聪明的著述。
此书亦有短处。他日当为作一评，评其得失。
得经农信（朱经），转送与他的妹子一看。
下午游公园，铁如（郑寿仁）、文伯（王）、慰慈
（张祖训）、梦麟诸位，谈近日教职员罢工事。前日政府提
出三条办法，已过国务会议，咋日政府正式宣布此三条
一九二一年: 241-
办法（附录上方），故今日教职员代表联席会议议决取消
辞职。但上课尚未定期，因为还有一些善后办法未了。明
日与后日各校将开大会，我当去看看。
后为“五四”后之第二周年。《晨报》与《半周刊》
皆将出“纪念增刊”，他们要我做文章。我自公园回来，
已九点半了，想出一个敢巧的法子，做了一篇文章，章洛
声为我抄了一份。
