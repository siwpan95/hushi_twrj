# 1946年7月5日

今大中午，上海才有“领港”Polit出来，船下午开
到吴淞口。又须等第二个“领港”可以进黄浦。
直到五点，打晚饭钟了，尚无入港消息。我们都去吃
饭，饭后大家在船面跳望，忽见两只船向我们的船开来。
一只船上似有中国人。细着是张景文（福运）与祖望，开
近了始见顾一樵。人是报馆记者等等，另一船是Judge
CornellFrankiinC·富兰克林了来接他太太和儿子。
我坐这船先离船，九时到海关码头，点半到Broad-
wayMansions【百老汇大厦】，受市政府吴国桢先生的
招待。
十一点，始见冬秀，九年不见他了
