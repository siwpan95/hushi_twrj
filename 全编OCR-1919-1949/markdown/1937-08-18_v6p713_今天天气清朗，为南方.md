# 1937年8月18日

今天天气清朗，为南方秋天的好天气。敌机终日未来。
下午六点，与慰慈、逵羽、枚荪同出门，邀了吴景超
夫人同到大三元吃饭，饭后我价同到后湖，雇了一只船，
荡遍湖中，月己将圆，光彩绝好。湖上只有我们一只船，
荷花在月光里不很出色，湖水映着月光，凄清动人。湖中
有两处插有标竿，摇船的女人说，这都是前天丢下炸弹之
处。我们坐了一点多钟的船，上岸又步行了半点多钟，才
离开湖上。枚荪说，我们真是苦中作乐。
回到教育部，始知周佛海先生有电话来约我去谈话，
他送车来接，我到那边见着高宗武、程沧波、梅恩平、顾
祝同、郭心崧诸君，谈不到一点钟，又听见飞机警号，我
看表正是十二点。佛海家有地下室，颇宽澈，大家走下
去，团坐闲谈。不听见什么轰炸声。解严时已过“点一
刻了。
希圣今早七点过江去接夫人与小孩，到半夜还不曾
回来。
景超有电，改于十六日从海参威回国。
--九三七年:705:
