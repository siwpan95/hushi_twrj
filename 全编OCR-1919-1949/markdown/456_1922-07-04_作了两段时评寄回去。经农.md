# 1922年7月4日

作了两段时评寄回去。经农自上海来。
下午，分组会议，通过了“推行国语教育”一案，我
打消了三个议案。
四时，到筹划全国教育经费委员会，他们正在谈赔款
事。江庸报告日本赔款情形，说话浅陋之至，甚至于提议
用“五校合同”（东京高等、工业、师范、千叶、山口商业）为
耸动日本退还赔款的条件！此人有点时名，原来只是一个
庸人！汤中报告日本赔款情形，颇颊好。梦麟报告美国下院
已通过退还赔款余数。此事大可喜。
到梦麟处吃饭，饭后往见美国新来的推士（Twiss）
先生，同见者在君、敦复、景阳、经农、何鲁、吴承落、
竺可桢。我们组织了一个委员会，帮助推士。推士是改进
社请来调查中学的科学教学法的。今天听他谈话，都还
一九二二年:717:
中肯。
