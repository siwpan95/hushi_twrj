# 1937年4月28日

雪艇来电话，约下午五点谈话，
我借车出门，往中央研究院，见着孟真、孟和、王显
廷等，略谈评议会议案事。到国际联欢社赴驭方、潘光迥
约吃饭。
访高君珊，不遇。访驭方、慰慈，见张公权部长谈半
点钟，他似很高兴。
访雪艇、书贻久谈。他们要中基会捐十五万元为义务
教育费。我力拒之，后来雪艇提议，改为十万元，并提议
明年（1938年度）起由教育部担任北平图书馆购书费--万
元。我答应代达此意。雪艇力劝我参加东京的世界教育
会议。
在孟和家吃饭，见汪缉斋及性仁。
访在君夫人。访君珊，稍谈梦旦碑事。
晚十一点开车往上海。
