# 1921年6月5日

今天下午本有各界联合会召集的国民大会，政府怕极
了，今天到处都是武装的军警，天安门两旁马队林立，中
央公园也不许开了。国民大会遂开不成了。
吴又陵来谈。孟和、铁如、守常等来谈。
下午，北大教职员开大会，联席会议的几个“重要”
人，都不敢出席，谭仲逵躲到法国医院去了广。沈兼士自首
善医院来，报告今天军警围守医院，不许人入内看视受伤
教职员。他又说，院长方君跑了，院中医药与饮食都不周
全。我听了急请孟和打电话寻严季约（首善的副晓长），请
他照料。沈君后来告诉我说，他这番是故意过甚其辞，要
笃动人的。这种手段，我很不赞成。政府很注意夷初，监
视最严。夷初想移到法国医院，警察不放他走。其实他尽
可不必想走。
是夜杜威先生自西山回来，我托他转告美国各医院，
请他们去首善医院设法把夷初移出来。他答应去办。
