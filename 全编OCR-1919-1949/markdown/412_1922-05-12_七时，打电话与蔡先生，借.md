# 1922年5月12日

七时，打电话与蔡先生，借他的家里并会，讨论《我
们的主张》。其余各人，也在电话上约定十一时相见。
上课，讲魏晋的想：（1）自然主义的宇宙观，（2)
个人主义的人生观，（3）虚无主义的政治观，（4）出世主
义（神仙修炼等)。
十一时，在蔡宅开会，到者：梁漱冥、李守常、孟
和、孟徐、汤尔和、徐伯轩（未约他，偶相值）、经农等。
他们都赞成了，都列名做提议人。蔡先生留我们吃饭；饭
后他们都散了，我独与蔡先生闲谈。三时，玉亮畴、罗君
任也来，他们咯有讨论，修改了几处，也都列名。连知
行、在君、玉伯秋、文伯和我，共15人。
下年，孟徐自行取消，加入一涵、慰慈，共十六人。
下午四时，开教务会议。
