# 1931年8月16日

祖望游水颇有进步，今天在君估计他能游二丈左右。
决计明天回去了。今天在君和我在海滩上闲步，他用
昨晚我们背诵的元送白居易的原韵作诗两首送我。在君
近年偶作七言律诗，多不留稿，这可背产许多给我听，其
中颇有好句。我劝他不要做律诗，多做绝句，绝句是可以
存留的旧休，律诗必不可存在了。
送适之
用元微之赠白香山原韵
留君至再君休怪，十日流连别更难。
从此听涛深夜坐，海天漠漠不成欢。
逢君每觉青来眼，顾我而今白到须。
此别原知旬日事，小儿女态未能无。
在君亲笔写此二诗，已取出影印，故我补写此一页。
适之廿五，一，廿二。
