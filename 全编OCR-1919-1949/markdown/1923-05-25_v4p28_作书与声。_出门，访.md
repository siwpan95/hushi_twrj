# 1923年5月25日

作书与声。
出门，访郭沫若、郁达夫、成仿吾。结束了场小小的
笔墨官司。借都益处宴请原放和他的未婚妻吴女土。到者
十八人。
到古书流通处。未买书。
访黄钟医生。两个肿都收口了，第三个又快起来。我
想服冬秀寄来之中药方，孟邹们不许我服，把方也抢去了。
①此后“手稿本"附有剪报-则，题为《张季直评苏省教育一发表与黄
任之论教育书一—极力攻击新式教育》，无报名、无日期，从略。
编者
胡适日记全编(四）
嗣稻来。
