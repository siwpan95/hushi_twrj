# 1922年3月18日

因足伤，久不洗浴，今日洗浴，也是一件快事。
到六国饭店访斯托洪（Stockholm）大学教授西伦（Os-
vald Siren)。此君专治美术史，很注意中国的美术；他说中
国的美术品所代表的精神的意境，比西洋美术品更多，因
为中国美术不拘守物质上的限制，技术更自由，故能表现
抽象的观念更深刻。我们谈的很畅快，他把他的书“Es-
sentials in Art”【《艺术的本质》］送给我。
四时，到女高师，为他们的英文部学生讲演，题为
《演说的要点》。（用英文。）
晚，到雨花春吃饭，主人为黎劭西，客为玄同、汪怡
庵、陆雨庵、卫挺生。我们大谈“国语”问题。
雨庵家中闹鬼，怪异百出，逼得他一家不得不搬；一
时不能得房子，“鬼”偏不许迟延，限日搬出。所以他一
家现住在雨花春楼上的公寓内。搬出之后，房主雇一贫人
住在里面看门。次日泥水匠入内，见此人已被火烧死；上
:586:胡适日记全编(三）
身肉尽见脏腑，头上肉尽见筋。此人跪在地上而死，室上
什物皆未被烧，只有布被上烧了一个大洞。此事已经官验
过，确系烧死。一一一此事确甚可怪；但家中怪异多不可
信，因雨庵自己皆未亲见过；只见一次“鬼”附一一个老妈
身上说话，声音语腔皆变成男音。此仍可疑。至于贫人的
烧死，当系“偶合”。烧死的原因必系平常的火，贫人或
喝醉了酒，致招此祸。不幸他的死恰当搬家的次日，故遂
现出一个“因果”的关系了。①
