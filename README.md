## 技术要点

- **编码**：站点 `charset=gb2312`，统一按 **GB18030** 解码。
- **Brotli 坑**：请求头强制 `Accept-Encoding: identity` —— 标准库 urllib 不认 br，否则会「200 但乱码、正文全空」的静默失败。
- **正文定位**：`<td class="t50">`（标题）之后**第一个无 class 且非空的 `<td>`**；两分册均通过「每篇恰好命中 1 个正文单元格」校验。
- **卷号继承**：留学日记条目标题多数不带卷号，故按文件顺序从前一个「卷 X」卷首页**继承卷号**；年份取自卷首页的日期范围文本。
- **跨卷图片重名**：保存为 `{卷目录}_{原名}`（如 `lx2_t05.jpg`），避免覆盖。
- **礼貌抓取**：4–5 线程、失败指数退避重试 + 串行补抓，1241 页 0 失败。
- **B 站 412 指纹风控**：`/x/article/view` 对非浏览器 TLS 指纹一律 412，纯 HTTP 库（urllib/requests）无论怎么伪装头部都无解；改用**无头 Edge `--dump-dom`** 打 API URL 再解析 `<pre>`，零第三方依赖搞定。详见 `辑补-网络连载/README.md`。

## 阅读器功能

- 侧边栏：分册 → 卷/年份 → 条目，三级可折叠（辑补卷按年份分组）
- 全文搜索（标题 + 正文），命中高亮，实时显示匹配数
- `←` `→` 翻上一篇/下一篇；`A-` `A+` 调字号；窄屏抽屉式目录
- 通过 `#id` 锚点记忆当前篇目
