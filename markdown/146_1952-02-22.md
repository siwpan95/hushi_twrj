# 1952年2月22日

去年十一月初，罗伯特·帕特森同他的同事律师曾草一说帖给顾大使，说明，毛邦初的案子既决定用法律解决，则不设立实地调查委员会了。此说帖中说，若讼事进行，则毛、向必逃走。

当初我赞成他们的说帖主旨，并且曾力劝顾大使采用其说。当时少川与宋子文、董显光都不赞成此说帖。后来我又力劝少川采用说帖最后的“附白”，主张先进行法律手续。少川答应了。三日之后，诉讼即开始。

但我当初颇不信毛邦初会逃走。及今看来，他们的话果然验了。
