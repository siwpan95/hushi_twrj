# 卷十二 四三、《沁园春》誓诗

> 卷十二（1915–1916）　序号 831 / 1006　来源: [https://www.xuges.com/xdmj/hushi/lx3/124.htm](https://www.xuges.com/xdmj/hushi/lx3/124.htm)

---

（四月十三日初稿）

昨日读书不乐，因作一词自遣。

沁园春

更不伤春，更不悲秋，以此誓诗。任花开也好，花飞也好，月圆固好，日落何悲？我闻之曰，“从天而颂，孰与制天而用之”？更安用为苍天歌哭，作彼奴为！

文章革命何疑！且准备搴旗作健儿。要前空千古，下开百世，收他臭腐，还我神奇。为大中华，造新文学，此业吾曹欲让谁？诗材料，有簇新世界，供我驱驰。
