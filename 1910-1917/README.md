## 体例说明

留学日记是「卷 — 条」体例，不是逐日日期体例：

- 卷首页标题为「卷 X」，正文首行给出该卷日期范围（如 *民国三年（1914）八月十一日至九月十五日*）
- 条目标题形如「卷六 一、悉尔演说欧战原因」；卷一、卷二的大量日期条目标题直接是日期
  （如「一九一一年八月四日（星五）」）
- 序跋附录 4 条（初版影像、台北版自记、重印自序、自序）置于最前

## 解析要点

1. **卷号继承**：多数条目标题不带卷号，按文件顺序从前一个「卷 X」卷首页继承
   （首版曾误按标题正则归类，导致 359 条被错分到「附录」，已修正）。
2. **跨卷图片重名**：`t05.jpg` 在多个卷目录中都存在，落盘为 `lx_t05.jpg` / `lx2_t05.jpg` 等。
3. **重建需清空 markdown/**：若改动解析规则导致序号偏移，旧的 `.md` 会残留成孤儿文件
   并被后续构建误读 —— 重跑前 `rm -rf markdown/`。
4. 两条「正文过短」（seq 193/195）原文即仅「打牌。」二字，非解析失败。
