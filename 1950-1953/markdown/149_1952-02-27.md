# 1952年2月27日

上页粘的《梁漱溟不肯洗脑》一文的后三分之二（前一段失落了），使我很感叹。漱溟的父亲梁巨川先生在民国八年发愤自杀（也许是七年尾），原因不明，但大致是因为不满意于当时的政治社会。（看《胡适文存》四，P.989—996。又《新青年》六卷一号。）

漱溟今天的行为也是“殉道者”的精神，使我很佩服。“不能向不通处变”，不能“自昧其所知以从他人”，都是很可敬的。
