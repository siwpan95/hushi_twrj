## 技术要点

- **编码**：站点为 `charset=gb2312`，统一按 **GB18030** 解码（兼容罕用字）。
- **Brotli 坑**：标准库 `urllib` 不自动解码 `br`，故请求头强制 `Accept-Encoding: identity`，
  避免出现「200 但正文乱码」的静默失败。
- **正文定位**：正文位于 `<td class="t50">`（日期标题）之后**第一个无 class 且非空的 `<td>`**，
  后续 `<hr>` 单元格与页脚按 class 过滤。质检确认 235 篇**均恰好命中 1 个正文单元格**，无遗漏。
- **礼貌抓取**：4 线程、`User-Agent` 伪装、失败指数退避重试 + 串行补抓一轮，235 篇 0 失败。
- **断点续传**：`raw/` 已存在且 >200B 的文件自动跳过；`--force` 可强制重下。

## 复现

```bash
python crawl/fetch.py            # 1. 下载 235 篇 + 目录
python crawl/verify.py --dl-img  # 2. 质检 + 下载插图
python crawl/parse.py            # 3. 生成 markdown/ 全集 index.json
python crawl/build_reader.py     # 4. 生成阅读器.html + 全集.txt
```

仅需 Python 3 标准库，无需 pip 安装任何包。

## 阅读器功能

- 左侧目录按年份分组，可折叠；点击年份标题折叠该年
- 全文搜索（标题 + 正文），命中关键词高亮，实时显示匹配篇数
- `←` `→` 方向键翻上一篇/下一篇；右下角 `A-` `A+` 调节字号
- 窄屏（<820px）自动转为抽屉式目录，右上角 ☰ 唤出
